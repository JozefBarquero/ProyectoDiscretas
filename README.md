# Evaluador de Árboles de Expresión

Este proyecto es una herramienta interactiva diseñada. Permite la visualización y evaluación de expresiones matemáticas mediante el uso de estructuras de datos tipo árbol, facilitando el aprendizaje de los recorridos **Preorden, Inorden y Postorden**.

---

## Funcionalidades Principal

* **Calculadora de Recorridos:** Convierte expresiones de notación infija (estándar) a notaciones prefija (Preorden) y postfija (Postorden) en tiempo real.
* **Evaluación de Expresiones:** Resuelve operaciones matemáticas utilizando el algoritmo de evaluación de pilas basado en el recorrido de abajo hacia arriba del árbol.
* **Módulo de Práctica:** Incluye una serie de 20 ejercicios con dificultad escalable, desde operaciones simples hasta anidamiento profundo con paréntesis.
* **Interfaz Responsive:** Diseño adaptable para dispositivos móviles y escritorio, incluyendo un menú de navegación intuitivo.

---

## Tecnologías Utilizadas

* **HTML5 & CSS3:** Estructura semántica y diseño basado en variables modernas de CSS para una paleta de colores profesional.
* **JavaScript (Vanilla):** Implementación de lógica algorítmica sin dependencias externas.
    * **Algoritmo de Shunting Yard:** Para la conversión de expresiones.
    * **Tokenización:** Procesamiento de cadenas de texto mediante expresiones regulares.
    * **DOM Dinámico:** Generación automática de ejercicios y control de secciones.

---

## Conceptos Teóricos Aplicados

El sistema demuestra de forma práctica cómo una computadora procesa la jerarquía de operaciones:

1.  **Preorden (Raíz-Izq-Der):** Representa la estructura jerárquica inicial.
2.  **Inorden (Izq-Raíz-Der):** La forma humana legible de la ecuación.
3.  **Postorden (Izq-Der-Raíz):** Método óptimo para la liberación de memoria en estructuras y evaluación de pilas (Notación Polaca Inversa).

## 📦 Instalación y Uso

1.  Descarga los archivos `index.html`, `styles.css` y `script.js` en una misma carpeta.
2.  Abre el archivo `index.html` en cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
3.  Ingresa una expresión en la calculadora o navega a la sección de ejercicios para practicar.
